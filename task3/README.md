# Лексический анализатор строк

Программа для лексического анализа входного текста с выделением специальных символов командной оболочки.

## 📋 Описание

Программа читает строки из стандартного ввода (stdin), разбивает их на токены (слова), разделяя обычные слова и специальные символы shell. Выводит слова в исходном порядке и в лексикографическом порядке, а также подсчитывает количество специальных символов.

## 🎯 Функциональность

- ✅ Чтение строк произвольной длины из stdin до EOF
- ✅ Разделение на обычные слова и специальные символы
- ✅ Поддержка специальных символов: `|`, `||`, `&`, `&&`, `;`, `>`, `>>`, `<`, `(`, `)`
- ✅ Вывод слов в исходном порядке
- ✅ Сортировка слов в лексикографическом порядке
- ✅ Подсчет общего количества специальных символов
- ✅ Динамическое управление памятью без утечек

Основная функция программы

🔍 Алгоритм работы

Чтение данных: Блочное чтение через fscanf в буфер 256 байт
Извлечение символов: Функция getsym() поставляет символы из буфера
Разбор слов:

Пробельные символы: игнорируются или разделяют слова
Специальные символы: обрабатываются get_special_word()
Обычные символы: накапливаются в динамическом буфере
Сортировка: Пузырьковая сортировка списка строк
Вывод: Два представления - исходный и отсортированный порядок
Управление памятью: Все динамически выделенные ресурсы освобождаются
