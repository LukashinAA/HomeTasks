# 🐯 Задача "Тигр и смотритель"

## 📝 Описание задачи

Реализация взаимодействия между двумя процессами — «тигром» и «смотрителем» — с использованием механизмов межпроцессного взаимодействия (IPC) в операционных системах.

### Сценарий:
В клетке живёт тигр, который ест мясо из миски. Смотритель следит за миской и наполняет её, когда она пустеет. Смотритель не может войти в клетку, пока тигр не съел всё мясо.

### Требования:
1. Использование **разделяемой памяти** для хранения количества мяса
2. Использование **семафоров** для синхронизации доступа
3. Два независимых процесса (тигр и смотритель)
4. Корректное завершение всех процессов по сигналу `SIGINT` (Ctrl+C)
5. Освобождение всех ресурсов IPC при завершении

## 🏗️ Архитектура программы

### Процессы:
1. **Родительский процесс** — создаёт ресурсы и управляет завершением
2. **Процесс-тигр** — периодически ест мясо из миски
3. **Процесс-смотритель** — периодически проверяет и наполняет миску

### IPC-ресурсы:
- **Разделяемая память** (Shared Memory) — хранит количество мяса в миске
- **Семафор** (Semaphore) — обеспечивает взаимное исключение при доступе к миске

## 🔧 Используемые системные вызовы

### Работа с разделяемой памятью:
```c
shmget()  // Создание разделяемой памяти
shmat()   // Подключение к разделяемой памяти  
shmdt()   // Отключение от разделяемой памяти
shmctl()  // Управление разделяемой памятью (удаление)
Работа с семафорами:

c
semget()  // Создание семафора
semctl()  // Управление семафором (инициализация, удаление)
semop()   // Операции над семафором (P/V операции)
Управление процессами:

c
fork()    // Создание нового процесса
wait()    // Ожидание завершения дочернего процесса
kill()    // Отправка сигнала процессу
exit()    // Завершение процесса
Обработка сигналов:

c
signal()  // Установка обработчика сигнала
atexit()  // Регистрация функции для вызова при завершении
📊 Логика работы

Алгоритм работы тигра:

text
1. Спит случайное время (1-3 секунды)
2. Захватывает семафор (операция P)
3. Если в миске есть мясо:
   - Съедает случайное количество (1-3 кг)
   - Обновляет количество мяса в миске
4. Освобождает семафор (операция V)
5. Возвращается к шагу 1
Алгоритм работы смотрителя:

text
1. Спит 2 секунды
2. Захватывает семафор (операция P)
3. Проверяет миску:
   - Если пусто → наполняет до 10 кг
   - Если есть мясо → просто проверяет
4. Освобождает семафор (операция V)
5. Возвращается к шагу 1

🎮 Управление программой

🔒 Механизм синхронизации

Семафор:

Начальное значение: 1 (ресурс свободен)
Операция P (sem_wait): уменьшает значение на 1
Операция V (sem_signal): увеличивает значение на 1
Гарантии:

Только один процесс может работать с миской одновременно
Исключается состояние гонки (race condition)
Предотвращается взаимная блокировка (deadlock)
🧹 Корректное завершение

При получении SIGINT (Ctrl+C):

Вызывается sigint_handler()
Вызывается exit(0)
Срабатывает atexit(cleanup)
В cleanup():

Убиваются процессы-дети
Отключается разделяемая память
Удаляются IPC-ресурсы из системы
