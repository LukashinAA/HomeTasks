Unix Commands Implementation on C

Проект содержит реализации основных Unix-команд на языке C.

📋 Список команд

Обязательные команды:

echo - вывод аргументов командной строки
pwd - вывод текущей рабочей директории
ls - вывод списка файлов в директории
Команды по выбору:

cp - копирование файлов (с защитой от копирования в себя)
wc - подсчёт строк, слов и символов в файлах
tail - вывод конца файла с поддержкой флагов
🛠 Компиляция

bash
# Компиляция всех программ
gcc -o echo echo.c
gcc -o pwd pwd.c
gcc -o ls ls.c
gcc -o cp cp.c
gcc -o wc wc.c
gcc -o tail tail.c
📖 Использование

echo

bash
./echo "Hello World"
./echo arg1 arg2 arg3
pwd

bash
./pwd
ls

bash
./ls          # файлы текущей директории
./ls /path    # файлы указанной директории
cp

bash
./cp file1.txt file2.txt    # копирование файла
./cp file.txt backup/       # копирование в директорию
wc

bash
./wc file.txt              # статистика одного файла
./wc file1.txt file2.txt   # статистика нескольких файлов
tail

bash
./tail file.txt           # последние 10 строк
./tail -5 file.txt        # последние 5 строк
./tail +10 file.txt       # начиная с 10-й строки
🔧 Используемые системные вызовы и функции

Базовые функции ввода-вывода

printf() - форматированный вывод
fopen()/fclose() - открытие/закрытие файлов (высокоуровневый ввод-вывод)
fgetc()/fgets() - посимвольное и построчное чтение файлов
fseek() - перемещение по файлу

Низкоуровневый ввод-вывод

open()/close() - открытие/закрытие файловых дескрипторов
read()/write() - чтение/запись данных
O_RDONLY/O_WRONLY - флаги режима открытия файлов
O_TRUNC - очистить файл, если такой уже существует 

Работа с файловой системой

getcwd() - получение текущей рабочей директории
opendir()/readdir()/closedir() - работа с директориями
struct dirent - структура информации о файле в директории
fstat()/stat() - получение информации о файле

Работа со строками и символами

strcmp() - сравнение строк
isspace() - проверка пробельных символов
isdigit() - проверка цифровых символов

Обработка ошибок

perror() - вывод системных ошибок
errno - глобальная переменная с кодом ошибки
⚡ Особенности реализаций

cp

Использует низкоуровневый ввод-вывод (open/read/write)
Копирует права доступа исходного файла через fstat()
Защита от копирования файла самого в себя с помощью strcmp()
Работает с бинарными и текстовыми файлами
wc

Использует высокоуровневый ввод-вывод (fgetc)
Подсчитывает строки, слова и символы
Работает с несколькими файлами одновременно
Корректно обрабатывает специальные символы с помощью isspace()
tail

Поддержка флагов -n и +n
Эффективное использование памяти (не хранит весь файл)
Использует fseek() для перемещения по файлу
Работает с большими файлами
ls

Использует функции работы с директориями (opendir/readdir)
Фильтрует скрытые файлы (начинающиеся с точки)
Поддерживает указание произвольного пути
