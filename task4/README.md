Проект: Реализация UNIX-утилит на C

Описание

Этот проект представляет собой набор простых UNIX-утилит, реализованных на языке C. Каждая программа является упрощенной версией стандартных команд Linux/Unix.

Содержание проекта

🟢 1. echo.c - вывод аргументов командной строки

Компиляция:

bash
gcc -o echo echo.c
Использование:

bash
./echo Hello World
# Вывод: Hello World
Особенности:

Выводит все аргументы командной строки через пробел
Добавляет перевод строки в конце
🟢 2. pwd.c - вывод текущей директории

Компиляция:

bash
gcc -o pwd pwd.c
Использование:

bash
./pwd
# Вывод: /home/user/current_directory
Особенности:

Использует системный вызов getcwd()
Обрабатывает ошибки получения пути
🟢 3. ls.c - список файлов в директории

Компиляция:

bash
gcc -o ls ls.c
Использование:

bash
./ls          # список файлов в текущей директории
./ls /path    # список файлов в указанной директории
Особенности:

Не показывает скрытые файлы (начинающиеся с точки)
Использует функции работы с директориями: opendir(), readdir(), closedir()
🔵 4. cp.c - копирование файлов

Компиляция:

bash
gcc -o cp cp.c
Использование:

bash
./cp source.txt destination.txt
Особенности:

Проверяет, что исходный и целевой файлы разные
Сохраняет права доступа исходного файла
Использует буферизированное чтение/запись (4KB буфер)
Обрабатывает ошибки открытия файлов
🟡 5. wc.c - подсчет строк, слов и символов

Компиляция:

bash
gcc -o wc wc.c
Использование:

bash
./wc file.txt
./wc file1.txt file2.txt
Вывод:

text
lines words chars filename
Особенности:

Поддерживает обработку нескольких файлов
Использует логику определения слов через пробельные символы
Обрабатывает ошибки открытия файлов
🔴 6. tail.c - вывод конца файла

Компиляция:

bash
gcc -o tail tail.c
Использование:

bash
./tail file.txt              # последние 10 строк
./tail -5 file.txt           # последние 5 строк
./tail +3 file.txt           # начиная с 3-й строки до конца
Особенности:

Поддерживает два режима: -n (последние n строк) и +n (с n-й строки)
Парсит аргументы командной строки
Эффективно работает с большими файлами
Требования

Компилятор GCC
Операционная система Linux/Unix/macOS
Стандартные библиотеки C
Компиляция всех программ

bash
chmod +x compile_all.sh
./compile_all.sh
Особенности реализации

Все программы используют стандартные библиотеки C
Реализована обработка ошибок
Код хорошо документирован
Соответствует поведению стандартных UNIX-утилит
Назначение проекта

Проект демонстрирует:

Работу с файловой системой в C
Обработку аргументов командной строки
Использование системных вызовов
Принципы работы стандартных UNIX-утилит
